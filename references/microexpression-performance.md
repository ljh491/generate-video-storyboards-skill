# 微表情演绎知识库（后续分镜内部参考）

来源：用户提供的 5 份 Seedance 2.0 微情绪/眼神/哭/笑/综合提示词文档。

## 一、调用原则

1. 先确定人物的“表层情绪、真实内心、触发事件、最终落点”，再选微动作；不按情绪名机械拼贴。
2. 每个 4—10 秒生成段只保留一条清楚的情绪弧线，通常拆为 3—5 个节拍。
3. 微表情以眼神为主轴，唇线、下颌、喉结、呼吸、鼻翼和肩颈作辅证；同一节拍避免全脸同时夸张变化。
4. 区分三层信息：表演（演员做什么）、摄影（景别/机位/运动/景深）、环境（光线/风/发丝/服装）。输出分镜时分层书写，避免提示词互相污染。
5. 优先写可观察、可执行的变化：聚焦/失焦、眼睑下压、下眼睑颤动、唇线抿紧、单侧嘴角牵起、喉头滚动、呼吸停顿等；少用只有抽象形容词的句子。
6. 强情绪不等于瞪眼、龇牙、持续流泪。克制通常更有张力：上眼睑略沉、目光锁定、泪光蓄而不落、下颌紧绷、动作减少。
7. 情绪峰值之后必须有余韵：失焦、松弛、垂眸、轻叹、转身、呼吸恢复或表情回归平静，使段落有落点。

## 二、常用情绪弧线

- 隐忍蓄力 → 爆发/崩塌：静止或慢推铺垫；眼尾泛红、鼻尖微颤、牙关与下颌收紧；最后才允许泪落、唇颤或动作爆发。
- 防备封闭 → 动容心动：目光由冷硬/躲闪转柔和聚焦；肩颈放松、呼吸放缓；耳尖或脸颊泛红、嘴角无意识上扬。
- 期待 → 落空 → 心死：眼底带光与聚焦开始；眉峰下垂、视线失焦；最终面部归于平直、人物与镜头拉开距离。
- 伪装假面 → 真实底色：表面笑意与眼底情绪相反；先保持礼貌弧度，再让眼神冷却、唇角垮塌或单侧冷笑显露真实内心。
- 怯懦迷茫 → 觉醒坚定：视线躲闪、呼吸不稳；短暂停顿/闭眼/呼气完成内在决定；重新抬眼直视，下颌稳定，动作简洁。
- 悲伤 → 强撑体面 → 破碎：震惊聚焦；冷笑/自嘲作为防御；含泪强笑；唇线瓦解、眼神失焦；泪水最后落下。
- 恐惧 → 接受 → 决绝：瞳孔扩散和眼睑颤动；闭眼长呼气；重新睁眼时目光平静、聚焦、无多余表情；再接决定性动作。
- 酸涩/委屈 → 和解/释然：眼尾红、唇线微抿、泪光不落；眉眼逐步舒展，嘴角浅笑，下颌与肩颈放松。
- 深情/心疼 → 破涕幸福：柔和锁视与薄泪；抿唇强忍；被对方触动后瞳孔亮起；笑意从嘴角扩散到眼尾，最后沉淀为安静笃定。
- 娇羞/心动：意外看见时呼吸一停、瞳孔轻扩；眼眸柔弯、垂眸与偷看交替；压笑失败；脸颊/耳根泛红；最终鼓起勇气重新直视。
- 冷笑/黑化：笑意先从眼底抽离；目光聚拢下沉；单侧嘴角极慢牵起，笑不达眼底；下巴微扬、眼睑略眯；避免直接跳到夸张凶狠。
- 爽朗大笑 → 收敛平静：嘴角大幅上扬、面颊抬起、眼周笑纹展开；笑声渐歇时眼中亮度先退，唇角回落，眉眼舒展至日常安然。

## 三、眼神与面部动作词典

### 眼睛

- 震惊：瞳孔骤缩或轻微扩散（按刺激性质选其一）、呼吸一滞、下眼睑轻颤；不默认圆瞪。
- 警惕：眼神锐利聚焦、上眼睑略下压、眉峰微蹙、视线锁定。
- 慌乱：视线快速躲闪/左右飘移、睫毛急眨、焦点反复丢失与找回。
- 心动：瞳孔轻扩、眼底亮起、视线想躲又回、眼尾逐渐柔弯。
- 悲伤：眼尾与眼眶泛红、下眼睑收紧或颤动、泪光从薄到满；落泪放在末端。
- 麻木：瞳孔轻微放大、持续失焦、睫毛静止、眼部肌肉松弛。
- 坚定：焦点收拢、目光不闪躲、眨眼减少、眼型自然稳定。
- 自嘲：先垂眸再抬眼，眼神疲倦了然；可配合单侧极淡冷笑。
- 温柔：眼周放松、眼尾柔和、目光持续而不逼迫，亮度增加但不锐利。

### 嘴、下颌与呼吸

- 强忍：唇线紧抿、下颌收紧、喉结滚动、呼吸短暂停顿。
- 破防：下唇或双唇轻颤、抿紧动作失效、嘴角原有弧度瓦解。
- 冷笑：单侧嘴角缓慢抬起，另一侧保持；笑意不进入眼睛。
- 真笑：嘴角、面颊、眼尾同步变化；面颊抬起，眼周自然出现笑纹。
- 压笑：嘴唇闭合、唇角细微抽动，眼尾先弯，随后笑意失控扩散。
- 下定决心：长呼气或短促吞咽后，唇线归于平直，下颌由紧绷转稳定。
- 崩溃：呼吸断裂、喉头剧烈滚动、胸腔/肩膀抽动；只在情绪峰值使用。

## 四、摄影与情绪的匹配

- 慢推/超慢推：隐忍、心动、动容、破防前的递进；焦点优先锁眼部和唇周。
- 急推/急停：突发震惊、愤怒临界点、真相揭露；只用于明确转折。
- 慢拉：情感抽离、麻木、孤独、心死；人物在画面中逐渐缩小。
- 固定镜头：最适合微表情连续变化，尤其是哭、强撑、决绝和假面剥落。
- 环绕/环摇：态度软化、黑化、内心拉扯；光影随角度变化但不能抢表演。
- 横摇/侧面揭示：人前与人后的双面情绪，或正面伪装与侧面破防。
- 虚实切换：恍惚、回忆、应激、精神游离；不可与大量面部动作同时堆叠。
- 高机位下降：脆弱、防备解除、安全感建立。
- 低机位仰拍/贴脸环绕：压迫、崩塌、认真对峙；谨慎使用，避免面部变形。

## 五、时长与节拍

- 0.25—0.5 秒：瞳孔变化、眼睑一颤、唇角抽动、吞咽、焦点切换等瞬时反应。
- 0.75—1.5 秒：一次清晰的情绪动作，如垂眸再抬眼、冷笑形成、眼眶泛红、含泪强笑。
- 1.5—2.5 秒：持续状态或复合转变，如从压抑到动容、从笑意到冷却。
- 4—6 秒段：建议 3 个节拍（触发—抵抗—落点）。
- 7—10 秒段：建议 4—5 个节拍（基线—触发—防御—峰值—余韵）。

## 六、后续分镜输出检查

- 人物开场基线是否明确？
- 触发事件在镜头内或画外是否明确？
- 每个节拍是否只承担一个主要变化？
- 眼神、嘴部、呼吸是否互相印证，而非同时抢戏？
- 是否写明对视对象/视线落点，避免无意义直视镜头？
- 是否保留停顿、屏息或静止，让变化可被看见？
- 运镜是否服务情绪，而非遮蔽微表情？
- 泪水、脸红、冒汗等生理反应是否有递进与合理时机？
- 表演是否避免“瞪眼式愤怒、瞬间大哭、全程乱颤、夸张抽搐”？
- 结尾是否有可定格的情绪落点？
